# TakeBinder

Osmo Pocket / DJI候補のMP4をファイル単位でコピー・日付整理する試験対応を追加しています。**DJIの分割録画は自動結合しません。** ファイル名だけでは機種を確定できず、Pocket実素材での検証も未実施です。[対応範囲・調査結果](docs/osmo-pocket-support.md)を参照してください。

[English](README.md)

TakeBinderは、GoProが分割保存したチャプターファイルを1回の撮影につき1本のMP4へまとめ、分かりやすいフォルダへ整理するアプリです。映像と音声を再エンコードせず、Gyroflowなどが利用するGoPro GPMFテレメトリも保持します。

リリース履歴は[変更履歴](CHANGELOG.md)を参照してください。

## 主な特長

- 同じ撮影に属するチャプターを自動検出し、正しい順序へ並べます。
- 映像・音声の品質を落とさず、複数チャプターを結合します。
- ジャイロ、加速度、GPSなどのGPMFデータを保持し、処理後に検証します。
- 1ファイルだけの撮影はリマックスせず、バイト単位でコピーします。
- 独立した撮影を並列処理します。
- Windows、macOS、Linuxで動作します。

## インストールと起動

TakeBinderはポータブルアプリとして配布します。[GitHub Releases](https://github.com/Surigoma/takebinder/releases)からお使いのOS向けパッケージを入手し、`SHA256SUMS.txt`で検証してから展開してください。展開先のファイルはすべて同じフォルダに置いたまま使用してください。

- Windows: `TakeBinder-win32-x64` 内の `TakeBinder.exe` を起動します。
- macOS: `TakeBinder.app` を起動します。
- Linux: `TakeBinder-linux-x64` 内の `takebinder` を起動します。

初回利用時は、**設定**を開いて**検証済みツールを取得**を選択してください。固定版のFFmpeg、ffprobe、mp4-mergeをダウンロードし、サイズとSHA-256を検証してからアプリ管理領域へ保存します。この取得にはインターネット接続が必要ですが、動画処理自体はローカルで行います。

## 基本的な使い方

1. **設定**を開き、表示言語と出力方法を選びます。
2. メディアツールが未取得の場合は、検証済みツールを取得します。
3. **変換**へ戻り、GoPro MP4が入っている入力フォルダを選択します。
4. 出力フォルダを選択します。
5. **フォルダを解析**を選択します。
6. 検出された撮影を確認します。**処理可能**と表示された撮影だけが自動処理されます。
7. **処理開始**を選択し、処理が終わるまでアプリを開いたままにします。

完了したファイル、警告、スキップ、失敗の内容は操作ログへ表示されます。JSONレポートが有効な場合は、詳しい処理結果も出力フォルダへ保存されます。

## 元動画を保護します

TakeBinderは入力動画を変更、移動、削除しないよう設計されています。

- 既存の出力を暗黙に上書きせず、安全な連番名を使用します。
- 一時ファイルへ処理し、検証に成功した場合だけ完成名へ確定します。
- 映像と音声はデコード・再エンコードせず、ストリームコピーします。
- 1ファイルだけの撮影はメディア処理せずコピーします。
- GPMF保持を検証できない出力は成功扱いにしません。
- キャンセルしても、すでに完了したファイルは削除しません。

動画はお使いのコンピューター内に留まり、クラウドサービスへアップロードされません。

## 主な設定

| 設定 | 内容 |
| --- | --- |
| ファイル名の形式 | `{YYYY}`、`{MM}`、`{DD}`、`{hh}`、`{mm}`、`{ss}`、`{NAME}`で出力名を作ります |
| 入力のサブフォルダ構造を維持 | 入力のフォルダ構造を出力フォルダ内へ再現します |
| 撮影日ごとのフォルダに出力 | `{YYYY}`、`{MM}`、`{DD}`を使って日付ごとに整理します |
| 元動画をコピー | 元チャプターを日付フォルダ内の `original` へコピーします |
| JSONレポート | 機械可読な処理結果を保存します |
| サブフォルダを含める | 入力フォルダより下のフォルダも走査します |
| SHA-256厳密検証 | バイトコピーが同一であることをSHA-256で検証します |
| 同時処理するグループ数 | 並列処理数を制限します。空欄なら自動設定します |

**初期設定に戻す**を使うと、表示言語と変換設定を初期値へ戻せます。保存済みの入力・出力フォルダは保持されます。

## 出力方法

- 既定のファイル名は `2026-08-09_143052_GX012345.mp4` のような形式です。
- 日付フォルダは既定で `2026-08-09` の形式です。
- 互換性のある複数チャプターは、1本のMP4へ結合します。
- 1ファイルだけの撮影は、そのままコピーします。
- 非互換、不完全、判定が不確実、GoPro以外、読み取り不能な入力は自動変換せず、理由を付けてスキップまたは失敗とします。

## 現在の制約

- H.264とH.265の変換や、解像度、フレームレート、ビットレート、HDR特性の変更は行いません。
- トリミング、タイムライン編集、プレビュー、手ぶれ補正、クラウドアップロード、360度動画のスティッチには対応していません。
- ストリーム互換性がないチャプターは、再エンコードへ切り替えず失敗とします。
- 実GoPro素材で映像・音声・`gpmd`のパケット単位検証に合格していますが、すべてのGoPro機種と撮影モードは未検証です。
- 現在はMVPです。交換できない大切な素材は、別の場所にもバックアップを保管してください。

## ソースからビルドする

開発にはNode.js 24、Corepack、Yarn 4.17.1、Go 1.26、Task 3.xが必要です。

```powershell
go install github.com/go-task/task/v3/cmd/task@v3.51.1
task install
task install:electron
task dev
```

実装詳細と安全要件は[製品仕様書](docs/SPECIFICATION.ja.md)を参照してください。
